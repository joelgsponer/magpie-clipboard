## session: radial wheel, R console, GitHub tool

- Chooser is now a radial wheel (`ToolChooserView`): wedge geometry in
  `tool(at:)`, pointer polled at 40 Hz while visible because a non-activating
  panel gets no reliable hover. Letters: C E D X L S R A T G.
- Math/calculator removed; `⌘Space R` is a persistent R process
  (`R --vanilla --quiet --no-echo`, stdin pipe). Protocol: `.magpie_run("<code>")`
  wrapper → visible values printed, errors/warnings/messages inline,
  `dev.off()` flushes PNG via `options(device)`, then `<<MAGPIE_DONE>>`.
  GOTCHA: `options(prompt="")` is invalid in R; non-interactive R halts on
  errors unless everything runs inside tryCatch (the wrapper does).
- GitHub tool: `gh api --paginate user/repos?affiliation=...` (149 repos), cached
  in UserDefaults; `gh issue create -R … --title --body` prints the URL last.
- SF Symbol `bubble.left.and.text.bubble.fill` renders blank on this macOS;
  `text.bubble.fill` works.
- URL scheme now toggles tools; `magpie://r?run=`, `magpie://github?repo=&title=&body=`,
  `magpie://chat?ask=` are the zero-keystroke test hooks.
